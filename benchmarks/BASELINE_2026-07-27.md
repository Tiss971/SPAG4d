# SPAG-4D reference baseline — 2026-07-27

Reference run of the **shipped production pipeline** across 10 diverse clips, to be the
comparison point for all future pipeline work. Reproduce with the harness invocation at the
bottom; raw per-video numbers are in [`baseline_2026-07-27.json`](baseline_2026-07-27.json).

## Config (frozen)

- **Code:** commit `5e2b571` (occlusion gate + skip-cap), branch `temporal-solutions`.
- **Pipeline config:** `bglock_sol1_median_w5` — `depth_correction="bglock"`, `depth_smoothing=True`,
  `depth_smoothing_window=5`, `depth_smoothing_method="median"`.
- **Generator:** `da360`.
- **Base kwargs:** `skip_step=4, stride=8, temporal_consistency=False, freeze_bg=False,
  outlier_pruning=0.3, grazing_angle=85.0, sparse_pruning=0.1`.
- **Env:** `SPAG_DETERMINISTIC=1` (reproducible), `SPAG_OCCL_FBGATE=1` (occlusion gate ON;
  defaults `SPAG_OCCL_FB_THRESH=3.0`, `SPAG_OCCL_MAX_SKIP=8`).
- **Hardware:** 4× GPU (PCI 0/1/2/4), one clip at a time per GPU.

## Reading the numbers

- **Background is very stable** — mean `bg_cv` 0.0073, and 9/10 clips have essentially zero
  >0.1 m spikes. This is the bglock win holding across the whole set. `atelier_1` is the only
  outlier (bg_cv 0.025, 3.2 % spike frames) — the one clip to watch for background regressions.
- **`fg_cv` is dominated by MattSwift (0.28)** — a single fast-moving foreground subject; its
  large genuine depth swing inflates the mean. Excluding it, mean `fg_cv` ≈ 0.038. Treat MattSwift
  as its own foreground-motion reference, not a stability failure.
- **Cost:** ~390 s/clip mean (skip_step=4), peak VRAM 32 GB mean / 58 GB max
  (`trop_long_embouteillage`, the longest clip at 338 analysed frames). VRAM is SAM3-bound — see B1.
- Occlusion gate was ON; it affects foreground track *persistence*, not these depth-CV metrics,
  so this run also serves as the "gate-on doesn't regress stability" check (it doesn't).

## Reproduce

```bash
export SPAG_DETERMINISTIC=1 SPAG_OCCL_FBGATE=1
python benchmark_solutions.py --gen da360 --configs bglock_sol1_median_w5 \
  --video-dir <dir with the 10 clips> --output <out>
```

The 10 clips: CIELE, Dispo_RDV, MattSwift, accident_electrique_02, atelier_1, boutique1_HQ,
circulation_site_1_edit_coupe, scene01, scene_03, trop_long_embouteillage
(from `/raid/mb273924/_DATASETS/uptale/data/videos`).

Technical Specification: 360° Video Pre-processing Pipeline for 3DGS🎯 Context & ObjectiveGoal: Convert a monocular equirectangular 360° video from a fixed camera into a consistent 3D Gaussian Splatting (3DGS) scene (6-DoF navigation).Core Problem: Mitigate temporal depth flickering (arbitrary scale and shift breathing) inherent to frame-by-frame monocular depth estimation models.Strategy: Absolute stabilization of the static background (~90% of the geometry) and affine alignment of individual frame depth maps over static regions.🛠️ Tech Stack & DependenciesDepth Model: DA360 (Native equirectangular monocular depth estimation).Motion Estimation: WAFT (Warping-Alone Field Transforms) for dense optical flow.Segmentation: Segment Anything Model 3.1 (SAM 3.1) with Object Multiplexing.Core Logic: OpenCV (Python), NumPy, Scikit-Learn (Least-Squares Regression).🔄 Pipeline Architecture & Data Flow[Input Video 360] ──> Time Median ──> Master Background ──> DA360 ──> Master Depth (D_ref)
        │
        ├──> WAFT Flow ──> DIoU Tracker ──> SAM 3.1 ──> Dynamic Masks (M_i)
        │                                                     │
        └──> Frame i Depth (D_i) ── [Affine Alignment over 1-M_i] ──> Aligned Depth Map i
Step 1: Geometry Initialization (Master Frame)Compute Temporal Median: Sample the video (e.g., 2 fps) to compute a temporal median image, eliminating moving objects.Output: master_background_360.jpgCompute Reference Depth: Run DA360 on the master background.Output: Master Depth Map ($D_{ref}$), representing the absolute rigid geometry of the room.Step 2: Advanced Tracking & Segmentation (WAFT + SAM 3.1)Dense Optical Flow: Compute high-resolution flow fields using WAFT between frame $t$ and $t+1$.Occlusion & Consistency Check: Implement a bidirectional forward/backward flow error threshold. If the error spikes, flag an occlusion event and pause SAM 3's memory accumulation for that object ID to prevent track drift.Hybrid Distance-IoU (DIoU) Tracker:Detect bounding boxes (last_box) from WAFT active motion areas.Track object IDs across frames using a combined score: Priority to IoU overlapping. If the WAFT mask fragments (IoU drops to 0), fall back to Euclidean center distance normalized by object scale.Support up to 16 simultaneous objects via SAM 3's internal Object Multiplex mechanism.SAM 3.1 Propagation:Pass active boxes/points as spatial prompts into SAM 3.1.Optional enhancement: Explicitly warp spatial prompts using sparse flow vectors from WAFT: $(x_{t+1}, y_{t+1}) = (x_t + \Delta x, y_t + \Delta y)$ to manually anchor SAM's attention in high-velocity maneuvers.Output: Temporally stable binary sequence masks ($M_i$, where $1 = \text{motion}, 0 = \text{static background}$).Step 3: Affine Depth Alignment (Anti-Flickering)For each frame $i$:Isolate Static Region: Invert the frame mask: $M_{\text{static}, i} = 1 - M_i$.Morphological Expansion: Dilate $M_i$ by 5 to 15 pixels using OpenCV (cv2.dilate) before inversion. This absorbs the boundary blur (depth bleeding) generated by DA360 around moving foreground edges.Compute Real-Time Affine Parameters: Solve the least-squares linear regression only on pixels where $M_{\text{static}, i} == 1$:$$D_{\text{ref}} \approx s_i \cdot D_i + t_i$$Where $s_i$ is the scale factor and $t_i$ is the translation/shift offset.Align Full Map: Apply the transformation parameters to the entire depth map $D_i$:$$D_{\text{aligned}, i} = s_i \cdot D_i + t_i$$💾 Target Outputs for 3DGS DataloaderFor each video frame, the pre-processing agent must export:frame_xxxx.png: Original RGB frame.mask_xxxx.png: High-precision binary mask from SAM 3.1 (foreground/background separation).depth_xxxx.npy / .png: Globally aligned, flicker-free depth map.
